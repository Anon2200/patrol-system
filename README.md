# Патрульная служба колледжа — веб-приложение

Готовое веб-приложение на FastAPI + SQLite для учёта нарушений патрульной службой колледжа.

Ниже — пошаговая инструкция, как бесплатно разместить сайт в интернете без установки Python и без терминала.

## Что вы получите
* Форму для патрульных (вход по ФИО + ПИН-код `1234`, фиксация нарушений).
* Админ-панель (`/login`, пароль `1029384756`) с поиском по ФИО студента и типу нарушения, удалением записей и экспортом в CSV/Excel.
* Рабочую ссылку вида `https://patrol-system.onrender.com`, доступную с любого телефона или компьютера.

## Шаг 1. Создайте аккаунт на GitHub
1. Перейдите на [github.com](https://github.com) и нажмите **Sign up**.
2. Заполните почту, пароль, придумайте логин — это бесплатно.
3. Подтвердите почту по ссылке из письма.

## Шаг 2. Создайте репозиторий и загрузите файлы проекта
1. На GitHub нажмите зелёную кнопку **New** (или значок `+` → **New repository**).
2. Укажите имя репозитория, например `patrol-system`, и нажмите **Create repository**.
3. На странице пустого репозитория нажмите **uploading an existing file** (или **Add file** → **Upload files**).
4. Перетащите в окно браузера все файлы и папки из проекта:
   * `main.py`
   * `requirements.txt`
   * `render.yaml`
   * `README.md`
   * папку `templates` целиком (с файлами `patrol.html`, `login.html`, `admin.html`)
5. Прокрутите вниз и нажмите **Commit changes**.

> **Важно:** структура папок должна сохраниться — файл `main.py` должен лежать в корне репозитория, а HTML-шаблоны — внутри папки `templates`.

## Шаг 3. Создайте аккаунт на Render.com
1. Перейдите на [render.com](https://render.com) и нажмите **Get Started**.
2. Проще всего зарегистрироваться через кнопку **GitHub** — так Render сразу получит доступ к вашим репозиториям.

## Шаг 4. Разверните сайт
1. В панели Render нажмите **New +** → **Web Service**.
2. Выберите репозиторий `patrol-system`, который вы создали на Шаге 2, и нажмите **Connect**.
3. Render автоматически найдёт файл `render.yaml` и подставит настройки. Если этого не произошло, заполните поля вручную:
   * **Name**: `patrol-system`
   * **Environment / Runtime**: `Python 3`
   * **Build Command**: `pip install -r requirements.txt`
   * **Start Command**: `uvicorn main:app --host 0.0.0.0 --port $PORT`
   * **Instance Type**: `Free`
4. Нажмите **Create Web Service** (или **Deploy**).
5. Подождите 1–3 минуты, пока в логах не появится строка `Application startup complete`.

Готово! Ваш сайт доступен по ссылке вида `https://patrol-system.onrender.com` (точный адрес Render покажет вверху страницы сервиса).

## Как этим пользоваться

### Патрульные
1. Открыть ссылку сайта.
2. Выбрать своё ФИО из списка и ввести ПИН-код `1234`.
3. Заполнять форму нарушения — вход запоминается на 30 дней (можно выйти вручную кнопкой «Выйти»).

### Администратор
1. Перейти на `/login` (например `https://patrol-system.onrender.com/login`).
2. Ввести пароль `1029384756`.
3. На странице `/admin` доступны поиск по ФИО студента, фильтр по типу нарушения, удаление записей и кнопка «Экспорт в Excel (CSV)».

## Важные особенности бесплатного тарифа Render
* **База данных не постоянна.** На бесплатном плане Render диск сервиса пересоздаётся при каждом новом деплое (и иногда при перезапуске после засыпания), поэтому файл `patrol.db` может очищаться. Если нужно надёжное долговременное хранение — периодически делайте экспорт в CSV через админ-панель, либо (в будущем) подключите внешнюю базу данных (например, бесплатный PostgreSQL на Render) вместо SQLite.
* **«Засыпание» сервиса.** Бесплатные сервисы Render «засыпают» после ~15 минут без запросов и могут отвечать на первый запрос дольше обычного (до 30–60 секунд) — это нормально.
